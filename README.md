# Classification-Klasifikasi-
Implementation of machine learning classification algorithms to predict wine quality based on chemical features.

## Deskripsi
Klasifikasi ini bertujuan untuk memprediksi kualitas wine berdasarkan fitur-fitur kimiawi menggunakan beberapa algoritma machine learning klasifikasi.

## Algoritma yang Digunakan
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- CatBoost
- Gradient Boosting

## Tahapan Analisis
1. Import library
2. Load dataset
3. Exploratory Data Analysis (EDA)
4. Pengecekan missing value
5. Pengecekan dan penanganan outlier
6. Preprocessing data
7. Feature scaling
8. Split data training dan validasi
9. Pembuatan model klasifikasi
10. Evaluasi model
11. Perbandingan performa model
12. Prediksi data testing
13. Export hasil prediksi CSV

## Hasil
Berdasarkan hasil perbandingan model, algoritma terbaik yang diperoleh adalah Gradient Boosting dengan accuracy sebesar 63.95%.

## File
- `UTS.ipynb` → notebook analisis
- `data_training.csv` → dataset training
- `data_testing.csv` → dataset testing
- `Training_clean.csv` → dataset hasil preprocessing
- `hasilprediksi_128.csv` → hasil prediksi quality wine
